# Benutzerhandbuch — LinkHub

> Für alle Mitarbeiter sowie Manager. Wird bei jedem Release mitgepflegt.

## Das Portal (ohne Anmeldung)
LinkHub ist die Startseite für alle Web-Applikationen des Unternehmens —
einfach im Browser öffnen, eine Anmeldung ist **nicht** nötig.

- **Filtern**: Oben wählst du deinen Bereich (z. B. Produktion); darunter
  erscheinen die Abteilungen des Bereichs. „Alle" zeigt den kompletten
  Katalog.
- **Suchen**: Das Suchfeld filtert live über Name, Beschreibung und
  Kategorie.
- **Öffnen**: Jede Kachel zeigt Monogramm, Name, Kategorie und eine kurze
  Beschreibung. „Öffnen" startet die Applikation in einem neuen Tab;
  „Manual" führt zur Anleitung, falls hinterlegt.
- **Hell/Dunkel**: Der Umschalter ◐ oben rechts wechselt das Farbschema
  und merkt sich deine Wahl; ohne Wahl folgt LinkHub der
  Systemeinstellung.
- **Sprache**: Neben dem ◐ sitzt der Sprachumschalter (Flagge).
  LinkHub gibt es komplett auf Deutsch und Englisch; beim ersten Besuch
  entscheidet die Browsersprache, danach wird deine Wahl gemerkt.
  Sind für Bereiche, Abteilungen, Kategorien oder Beschreibungen
  englische Texte gepflegt, werden diese in der englischen Ansicht
  angezeigt.

Fehlt eine Applikation oder stimmt ein Link nicht? Wende dich an die im
Portal genannten Ansprechpartner bzw. die IT — die Pflege dauert nur eine
Minute.

## Pflege (Manager)
Nach der Anmeldung (oben rechts, Windows-Konto) erscheint die Navigation
„Pflege".

### Applikationen
- **Neu anlegen / Bearbeiten**: Name, Beschreibung (ein Satz für die
  Kachel), Link zur Applikation, optional Link zum Manual, Kategorie,
  Sortierung, aktiv/inaktiv — Name und Beschreibung optional zusätzlich
  auf Englisch (leer = deutscher Text wird angezeigt).
- **Sichtbarkeit**: Ordne die Applikation Bereichen (gilt für den ganzen
  Bereich) und/oder einzelnen Abteilungen zu. Ohne Zuordnung erscheint sie
  nur im Filter „Alle" — sinnvoll für Anwendungen, die alle betreffen
  (z. B. Webmail, Zeiterfassung).
- **Inaktiv** schaltet eine Kachel aus dem Portal, ohne sie zu löschen.

### Struktur
Die Seite „Struktur" pflegt die Filterebenen und Abschnitte direkt in
der Tabelle (Werte ändern und „Speichern" in der Zeile klicken):
- **Bereiche** — oberste Filterebene (Reihenfolge über die Sortierung)
- **Abteilungen** — je Bereich, zweite Filterebene
- **Kategorien** — Abschnitte der Startseite; Applikationen ohne
  Kategorie stehen unter „Weitere"

Für jeden Eintrag lässt sich optional ein englischer Anzeigename
pflegen. Beim Löschen bleiben Applikationen grundsätzlich erhalten — sie
verlieren nur die Zuordnung.

## Anmeldung
Melde dich mit deinem Windows-Konto an. Was du pflegen darfst, ergibt sich
aus deinen AD-Gruppen — bei Fragen zur Berechtigung wende dich an die
Administration. Im Demo-Modus gelten `admin/admin` und `manager/manager`.
